# Product Documentation

FEEXSYSTEMS is presented as a living engineering intelligence environment rather than a conventional portfolio.

## Product surfaces

- **Spatial World** — 3D World Model projection.
- **Navigator** — grounded search, retrieval, and explanation.
- **Omni-Command** — multi-modal orchestration.
- **Evidence Fabric** — provenance and trust inspection.
- **Project Explorer** — ecosystem-level system discovery.
- **Living Intelligence** — ambient model-backed assistance.

## Product doctrine

The product experience should expose the relationship between system reality, evidence, reasoning, and spatial interaction.

## Product language

Use precise engineering terminology. Avoid unsupported superlatives. Product claims should be traceable to implemented capabilities or clearly labeled as roadmap architecture.
