# FEEXSYSTEMS Brand System

The canonical brand library defines FEEXSYSTEMS as an architectural, graph-based, evidence-oriented, living visual system.

## Core axioms

- Architectural, not decorative.
- Graph, not list.
- Evidence, not claims.
- Living substrate.

## Canonical source

The existing [FEEXSYSTEMS Brand Assets Library](../brand-assets/FEEXSYSTEMS_Brand_Assets_Library.md) remains the detailed identity reference during this documentation migration.

## Asset areas

- Identity and mark
- Color system
- Typography
- Iconography
- World identities
- Telemetry components
- Spatial/3D visual language
- Voice and lexicon
- Screenshots
