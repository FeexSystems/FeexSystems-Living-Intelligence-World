# Spatial World

The Spatial World is the Three.js/WebGL projection of the FEEXSYSTEMS World Model.

## Spatial meaning

3D position and movement are intended to communicate:

- Graph topology
- Cluster density
- Relationship distance
- Entity focus
- System-world boundaries

## Runtime concepts

The documented spatial experience includes:

- Planetary/core visualization
- Orbital system worlds
- Relationship/lattice structures
- Particle fields
- Node inspection
- Camera focus transitions
- Runtime telemetry

## Design principle

Spatial rendering is a semantic projection, not a decorative layer.

The source World Model remains canonical even when the spatial projection is interactive.
