# Omni-Command

Omni-Command is the multi-modal orchestration surface for interacting with the FEEXSYSTEMS World Model.

## Contract

Natural-language requests are translated into validated orchestration structures before execution.

The repository documents a Zod-validated orchestration contract and streaming SSE execution traces.

## Execution surfaces

The command stage can coordinate experiences such as:

- Code and artifact inspection
- 3D graph focus
- Evidence inspection
- Metrics views
- World Model navigation
- Voice navigation

## Streaming

The documented production API includes synchronous orchestration and a Server-Sent Events streaming route for execution traces.

## Boundary

Omni-Command orchestrates interactions with system state. It does not replace the World Model with conversational state.
