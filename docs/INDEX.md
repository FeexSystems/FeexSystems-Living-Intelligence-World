## 🛠️ Using the OpenAPI Specification

### View Documentation

```bash
# Interactive (Swagger UI)
docker run -p 8080:8080 \
  -e SWAGGER_JSON=/specs/openapi.3.0.yaml \
  -v $(pwd)/docs:/specs \
  swaggerapi/swagger-ui

# Beautiful static (Redoc)
docker run -p 8000:8080 \
  -e SPEC_URL=file:///specs/openapi.3.0.yaml \
  -v $(pwd)/docs:/specs \
  redocly/redoc

# Online (no install needed)
# https://editor.swagger.io → Import File
```

### Generate Client

```bash
# TypeScript
openapi-generator-cli generate \
  -i docs/openapi.3.0.yaml \
  -g typescript-fetch \
  -o generated/typescript-client

# Python
openapi-generator-cli generate \
  -i docs/openapi.3.0.yaml \
  -g python \
  -o generated/python-client

# Go, Java, C#, etc.
```

### Test Endpoints

```bash
# Postman: Import openapi.3.0.yaml
# Insomnia: Import openapi.3.0.yaml
# cURL: See examples in API_QUICK_REFERENCE.md
# Newman: CLI testing (npm install -g newman)
```
