# Pure CSS halftone patterns: dots, lines, circles

A Pen created on CodePen.

Original URL: [https://codepen.io/editor/Feexara/pen/01a056f3-9af6-7f1b-a031-e52a5d38813d](https://codepen.io/editor/Feexara/pen/01a056f3-9af6-7f1b-a031-e52a5d38813d).

A project overdue. As an 80's/90's kid, I was obsessed with printing technology - and especially halftone patterns. I've long theorized that these patterns - be it dots, lines or circles (which I also toyed around with in photo editing software) - could also be easily automated with CSS: add the pattern of choice on top of your photo of choice, then tweak brightness and contrast on the wrapper of the two .
Have fun: pick between pattern types, pattern sizes, brightness settings, and switch photos!
