# Vendored Hyperiux Effects

The folders in this directory are vendored copies of the free/open-source
effects from
[Hyperiux Immersion Labs — hyperiux-components](https://github.com/Hyperiux-Immersion-Labs/hyperiux-components),
licensed under **MPL-2.0** (see `LICENSE_EFFECTS` in that repository and each
file's `Built using Hyperiux Vault` header).

- Source registry: `registry/index.json` — 75 free-tier effects.
- `manifest.json` / `dependencies.json` are generated by
  `scripts/vendor-hyperiux.mjs` (re-run it after updating the upstream clone).
- Pro-tier effects are intentionally NOT vendored.

## Local adaptations

- `"use client"` directives stripped (Vite does not need them).
- `gsap/dist/*` imports normalized to `gsap/*`.
- `next-transition-router` replaced by `./_lib/transition-router` (React
  Router/Vite shim exposing the same `leave`/`enter` contract; trigger wipes
  via `playHyperiuxTransition()` or the `hyperiux:transition` window event).
- `next/font/google` in `variable-text-proximity` replaced by the
  `.hv-roboto-flex` class (Roboto Flex loaded via `index.html`).
