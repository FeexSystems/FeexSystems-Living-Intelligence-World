# FeexSystems Canonical World Model
> FeexSystems turns code-level engineering evidence into an explorable, verifiable World Model. Canonical identity and relationships come from the server-backed model; AI layers interpret rather than invent facts.

3. **FARMPLUG AI** — Voice crop guidance, soil sensor fusion, and agricultural intelligence.
4. **FIREHOUSE GRILLS** — Connected culinary hardware and precision thermal control.
5. **FEEXKEEAUTH SECURITY** — High-assurance defense, cryptography, and zero-trust security.
6. **KAPPAXCHANGEFIN** — Decentralized finance, trading, and liquidity infrastructure.
7. **RENTALL SMARTS HOMES** — Autonomous property management and living-environment IoT.
8. **FEEX WORLD OS** — The authoritative engineering intelligence World Model.
9. **VYRA LABS** — Creator intelligence, social identity, and behavioral commerce.

## Five AI Core missions
- **001 — AI Operations:** Provider-neutral orchestration, idempotent workflow lifecycle, and execution tracing.
- **002 — Shared Platform:** Tenant isolation, team RBAC, and AI gateway hardening.
- **003 — World Intelligence:** Canonical facts separated from dynamic interpretations.
- **004 — Domain Products:** RentAll property mesh and FarmPlug agricultural intelligence.
- **005 — Knowledge & Document AI:** SHA-256 evidence hashing and citation validation.

## Evidence and APIs
Evidence is intended to connect claims to repository, branch, commit SHA, file path, and observation time. Public API entry points include `GET /api/world-model/projects`, `GET /api/world-model/graph`, `GET /api/world-model/evidence/{projectId}`, and `GET /api/world-model/navigator?q={query}`. Interactive docs and the raw OpenAPI schema are exposed at `/api/docs` and `/api/docs/spec.json` when enabled by the server environment.
