# Support

Thanks for using **FEEXSYSTEMS — Living Engineering Intelligence**. Here's where to get help, depending on
what you need.

## 📖 Documentation

Start with the docs — most questions are answered there:

- [**README**](README.md) — project overview, live links, and quick start.
- [**Contributing Guide**](CONTRIBUTING.md) — setup, standards, and the pull-request process.
- [**Frontend Guide**](client/CONTRIBUTING.md) — conventions for work inside `client/`.
- [**Architecture & Docs**](docs/) — World Model, Evidence Fabric, ingestion, and API references
  (Swagger UI is served at `GET /api/docs`).

## 💬 Questions & Discussions

- **Have a "how do I…" question?** Open a
  [GitHub Discussion](https://github.com/FeexSystems/FeexSystems-Living-Intelligence-World/discussions) (if
  enabled) or search existing issues first.
- **Found a bug?** Open an issue using the
  [bug report template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Want a new feature?** Use the
  [feature request template](.github/ISSUE_TEMPLATE/feature_request.md).

## 🔒 Security Vulnerabilities

Do **not** open a public issue for security problems. Report them privately by following
[**SECURITY.md**](SECURITY.md).

## ☁️ Platform / Account & Billing

For issues with the hosted platform ([feexsystems.codes](https://feexsystems.codes)), your account, or
subscription billing, contact the team through the support channel published on the site
([feexsystems.codes](https://feexsystems.codes)). Please **do not** post account details or personal
information in public issues.

## ⏱️ Response Expectations

This is a best-effort, community-supported project. We aim to triage new issues promptly, but there is **no
guaranteed SLA** on community support. Security reports are prioritized — see
[SECURITY.md](SECURITY.md).

## 🤝 Code of Conduct

All support interactions fall under our [**Code of Conduct**](CODE_OF_CONDUCT.md). Please be respectful and
constructive.
